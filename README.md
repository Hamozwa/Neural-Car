# Neural-Car
Application of Genetic Algorithm to make cars race around a 2D track in Godot Game Engine.

---

EDIT 2026: This project was made many years ago mostly as a learning exercise! This repo's implementation is extremely inefficient; if you're looking to actually make something similar, I'd suggest something like [GodotAIGym](https://lupoglaz.github.io/GodotAIGym/) or some other similar means of using a premade library. This repo still stays up as (a) a Godot simulation, (b) a naive, easy-to-understand implementation of the genetic algorithm, and (c) a sentimental project :)
